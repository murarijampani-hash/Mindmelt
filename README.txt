MINDMELT WEBSITE PACKAGE

This is the browser version of MindMelt. It does not require Google Play Store.

PUBLISH IT AS A WEBSITE
1. Ask a parent/guardian to help choose a trusted static website host.
2. Create a new static site on that host.
3. Upload the CONTENTS of this folder (index.html, manifest.webmanifest,
   service-worker.js, and the icons folder) to the site's public web root.
4. The host must provide HTTPS. Open the resulting HTTPS website address in Chrome.
5. In Chrome, use the menu and choose Install app or Add to Home screen.

The website is not online yet. This ZIP is the upload package; it does not create
an internet address by itself. Do not share passwords or payment details here.

CURRENT LIMITATIONS
- Quiz progress, tokens, rooms, and seller/buyer listings are stored in the
  current browser on the current device.
- Room codes and marketplace listings are not shared between different devices.
  Real online multiplayer and a shared marketplace require a backend/database.
- The current story library contains 60 original adventure and mystery books, each with 20 reading pages.


MICROSOFT OFFICE LINKS
- The Word, Excel, and PowerPoint sections open Microsoft's real web editors in separate browser tabs. MindMelt does not recreate those editors. Internet access is required; Microsoft may ask the user to sign in. A parent/guardian should help with account setup.

CODING SECTION
- The Coding tab opens the real Scratch online editor in a separate browser tab.
- It uses Scratch's actual editor and block set instead of an imitation.
- An internet connection is required. Scratch is a separate service operated by the Scratch Foundation; MindMelt is not affiliated with it.
- Scratch may require an account to save projects online. A parent/guardian can help with account setup.



WORLD STORYBOOK UPDATE
The World Storybooks section now contains 60 original adventure and mystery books: the original 10 expanded editions plus 50 new books. Every book has 20 reading pages with previous/next page controls.

BLOOK COLLECTION UPDATE
- The Blook Collection tab displays every MindBlook grouped by its pack.
- Each blook is marked as Owned (with the number collected) or Not collected.
- Each pack has an Open Pack button and shows its token cost.
- Collection and token data remain local to the current browser/device in this preview.


BLOOK RARITY UPDATE
- Packs now display their own themed cover artwork.
- Opening any themed pack rolls a rarity, then awards a random blook from that pack.
- Drop chances: Uncommon 50%, Rare 30%, Epic 14%, Legendary 5%, Chroma 0.6%, Mythical 0.4%.
- The six rarity tiers add up to 100%. Existing collected blooks are kept and shown as Uncommon if they were collected before this update.
- The word "crime" was interpreted as "Chroma", a common rarity tier in blook-style collection games.


CUSTOM MINDBLOOK CREATOR
Blook Studio lets a player create an original MindBlook by choosing a character, accessory, background colour and name. Saved custom designs appear in the player collection and in the Blook Collection page. Designs are stored locally in the browser on this preview device; they are not automatically shared with other players or devices. This is an original MindMelt feature and does not copy Blooket artwork or interface.


BLOOK RARITY ANIMATIONS
- Uncommon MindBlooks have a soft green dotted shimmer.
- Rare MindBlooks have moving blue stripes.
- Epic MindBlooks have a purple rotating pattern.
- Legendary MindBlooks have golden sparkles.
- Chroma MindBlooks have a shifting rainbow glow.
- Mythical MindBlooks have a cosmic starfield and orbit ring.
- Blook Studio lets creators choose the visual rarity effect for their custom design. This changes its appearance only; it does not change pack drop chances.
- Animations respect the device's reduced-motion accessibility setting.


WORLD CHAT PREVIEW
MindMelt includes public topic-room and private-chat preview screens. Messages, nickname, blocked users and reports are stored only in this browser using localStorage. No messages are delivered to other users. This is not a worldwide live chat service. Before enabling real global chat, connect a secure backend and implement age-appropriate account controls, friend consent, moderation, reporting, blocking, rate limits, privacy safeguards and a process for responding to reports. The UI blocks common email/phone/password/address disclosures, but this client-side check is not a substitute for server-side safety moderation.

Chat usernames: players choose a 3–16 character username using letters and numbers, including at least one letter and one number (for example, StarFox27). Friend lookup uses the exact username. The username is stored on the current device in this preview. Global username availability/uniqueness cannot be checked until a shared online account database is connected.
